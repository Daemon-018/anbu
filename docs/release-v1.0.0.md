# ANBU v1.0.0

The first public release of ANBU: a local, explainable risk scanner for Android APKs.
Point it at a file, get a 0–100 score, a plain-language verdict, and every quote that
justified it.

## What you can do with it

```bash
pipx install "git+https://github.com/Daemon-018/anbu.git"
anbu scan my-app.apk --out out/
anbu scan my-app.apk --out out/ --fail-on high   # CI gate, exit 3
```

It writes `out/my-app.json` and a self-contained `out/my-app.html`. Nothing in the APK
is executed, and no account or API key is needed.

## What is in this release

- **Safe ingest** — zip guards, size limits, SHA-256, refuses broken archives.
- **Extraction** — package identity, certificates, SDK levels, permissions, components,
  DEX statistics, strings, URLs, assets, packer fingerprints and entropy hints.
- **37 rules, 7 combinations** — SMS/OTP theft, accessibility abuse, overlays, droppers,
  ransomware, stalkerware, spyware, notification sniffing, C2 infrastructure.
- **Class ranker** — scores classes by suspicious calls and names, skips platform
  libraries, and slices the top ones for reading.
- **Optional AI pass** — `--llm` sends only ranked slices to an OpenAI-compatible
  endpoint. Every quote must match a fact extracted from the APK, or the finding is
  dropped. The model can never set the score.
- **Deterministic scoring** — saturating formula, combo bonuses, verdict bands,
  confidence and coverage. Packed apps are reported as *inconclusive*, never "low risk".
- **Reports** — JSON plus one HTML file with no external assets.
- **Offline test fixtures** — a synthetic malicious APK is built by hand (AXML + DEX),
  so tests need no JVM and no samples in the repository.

## `anbu-demo-sample.apk`

The attached APK is **not malware**. It is a harmless synthetic file generated by
`tests/fixtures/apk_builder.py` specifically for demos and tests. It contains no
executable classes: a hand-built manifest with high-risk permissions and a string-only
DEX with a fake bot URL. Scanning it produces 100/100 with the BANKER, OTP-STEALER and
SPYWARE patterns, which makes it a useful first run.

Build it yourself instead of downloading, if you prefer:

```bash
python tests/fixtures/apk_builder.py out/demo.apk
anbu scan out/demo.apk --out out/
```

## Limits, stated plainly

- Static analysis cannot see server-delivered logic, runtime-decrypted payloads, native
  code in `.so` files, or behaviour gated on device/region checks.
- "No known malicious signals" is not "safe".
- The score is a triage aid, not a guarantee and not a legal determination.
- Only analyse APKs you own or are authorised to inspect.

## Requirements

Python 3.10+ and `androguard`. No JVM, Android SDK, emulator, or paid service.
